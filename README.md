# Az-Zumratul Adabiyyatul Kamaliyyah

## Website v2
This rebuild follows the visual approach requested by the user: modern Arabic/Islamic educational institution, inspired by the supplied Ali Institute screen recording.

### Frontend
HTML + CSS + Vanilla JavaScript.

### Backend
Node.js + Express + JWT-ready role model + development JSON persistence.

### Academic structure
- Tamheediyyah
- Ibtidā’iyyah
- Ihdādiyyah
- Thanawiyyah

### Important
Replace placeholders with official school logo, photographs, leader profiles, phone/WhatsApp/email, programme details, fees and admission requirements. For production student records, migrate JSON data to PostgreSQL and use strong password hashing such as Argon2id or bcrypt.
